# Исправление секвенсора — 0.4.26

## Что изменено

- Удалено заполнение PAD/PIANO/PLUCK при `seq_init()`: новый проект и чистый запуск начинаются с пустых партий.
- `SEQ` + `OCT+` теперь очищает партии всех трёх синтов, все восемь паттернов каждого синта, сцены и аранжировку.
- Комбинация останавливает воспроизведение и отпускает ноты роллов, гармоний и арпеджиатора.
- После очистки открытый проект автоматически сохраняется в текущий слот FM-1. Это не даёт старой демо-партии вернуться после перезапуска.
- Сохранение пустого проекта больше не помечает пустые паттерны как занятые; явное копирование пустого паттерна по-прежнему создаёт отдельный паттерн.

## Сборка и установка

В Actions запустите workflow **Firmware** с версией `0.4.26`. Скачайте артефакт `demake-fwsc`, распакуйте его один раз и получите `demake-0.4.26.fwsc`. Установите этот файл через выбор файла на странице Install.

**Важно:** `web/firmware/demake-0.4.24.fwsc` в репозитории — прежний опубликованный бинарник, он не содержит этих исправлений. Автоустановка со страницы пока оставлена на проверенной версии 0.4.24; для проверки этих изменений используйте именно новый артефакт Actions. Новый пакет не публиковался как проверенный на физическом FM-1.

## Проверки исходников

- `host/dmk_host --selftest`: пройдено.
- Selftest под AddressSanitizer + UndefinedBehaviorSanitizer: пройдено.
- ARMv7-M soft-float компиляция: пройдена; запрещённых float helpers и 64-битного деления нет.
- Проверка на физическом FM-1 не выполнялась.
