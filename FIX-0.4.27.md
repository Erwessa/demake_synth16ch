# Исправление комбинации очистки — 0.4.27

## Что изменено

- `SEQ + OCT+` теперь распознаётся в обоих порядках нажатия: сначала SEQ, затем OCT+; либо сначала OCT+, затем SEQ.
- Это также исправляет одновременное нажатие: сканер панели FM-1 перечисляет OCT+ раньше SEQ, поэтому прежняя версия могла не распознать комбинацию, если кнопки были нажаты почти одновременно.
- После распознавания комбинации очищаются паттерны всех трёх синтов, сцены и аранжировка; пустой проект сохраняется в текущий слот.
- Добавлены host self-tests для обоих порядков, включая проверку сохранения после перезапуска.

## Сборка и установка

Запустите GitHub Actions → **Firmware** с версией `0.4.27`. Скачайте артефакт `demake-fwsc`, распакуйте его и установите `demake-0.4.27.fwsc` через страницу Install.

Это исходный архив с исправлением, не готовый `.fwsc`. Сборка требует JieLi toolchain и AC79 SDK, которые workflow получает на GitHub Actions. Физическая проверка на FM-1 ещё не выполнена.
