# Пустой проект молчит, SEQ + OCT+ убирает и аккорды — 0.4.28

## Что было

«Демка» при включении — это была не запись в секвенсоре (там нот нет), а встроенная аккордовая прогрессия
**First snow**, выбранная по умолчанию: при PLAY она сама играла аккорды на синте 1. Комбинация SEQ + OCT+ стирала
паттерны, сцены и аранжировку, но прогрессию оставляла, поэтому после «очистки» PLAY всё равно играл аккорды.

## Что изменено

- Новый (пустой) проект начинается с прогрессии **User 1**, в ней нет аккордов, поэтому PLAY ничего не играет.
  Заводские прогрессии остаются в списке (CHORD, ручка PROGRESSION), их можно выбрать вручную.
- **SEQ + OCT+** теперь заменяет выбранную прогрессию на первую пустую из User 1–4 во всех сценах (ваши записанные
  User-прогрессии не стираются; если все четыре заняты, выбор не меняется). Результат сохраняется в текущий слот.
- Selftest: пустой проект молчит под PLAY; пресет играет; после SEQ + OCT+ аккорды замолкают, а User-прогрессия
  с вашими аккордами остаётся нетронутой.
- Старые selftest, которым нужна была First snow по умолчанию, выбирают её явно.

## Сборка

GitHub Actions → **Firmware** → версия `0.4.28`. Физическая проверка на FM-1 не выполнена.
Проект, сохранённый на устройстве раньше, сохраняет выбранную в нём прогрессию; один раз выполните SEQ + OCT+.
